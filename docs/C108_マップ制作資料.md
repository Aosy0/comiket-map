## ホール別 島レイアウト

### 東1ホール
- 島の配置: 13島 横一列（各島は上下2段構成）
- ブロック名: ス, シ, サ, コ, ケ, ク, キ, カ, オ, エ, ウ, イ, ア
- サークル番号形式: 数字+枝番(a/b) 例: 01a, 01b, 02a, 02b
- 番号の並び: 上→下に増加。各島で左右対称（左列が増加・右列が減少）

### 東2ホール
- 島の配置: 14島（左: ヒ,ハ,ノ / ネ,ヌ,ニ / 右: ナ,ト,テ,ツ / チ,タ,ソ,セ）
- ブロック名: ヒ, ハ, ノ, ネ, ヌ, ニ, ナ, ト, テ, ツ, チ, タ, ソ, セ
- サークル番号形式: 数字a/b（a=左列, b=右列）、上→下に増加

### 東3ホール
- 島の配置: 12島（ア / ヨユヤモ / メムミマホヘツ の3群）
- ブロック名: ヒ, フ, ヘ, ホ, マ, ミ, ム, メ, モ, ヤ, ユ, ヨ
- サークル番号形式: ブロック名+数字 例: ア74, ヨ28

### 東7ホール
- 島の配置: 23島（上: A+M〜B の13、下: W〜N+A×2 の11）
- ブロック名: A〜W
- サークル番号形式: 数字のみ、各島 12行×2列 = 24個
- 並び: 左列25→36増加、右列24→13減少

### 西1ホール
- 島の配置: ふ,ひ,は,の,ね,ぬ,に,な,と,て,つ / む,み,ま,ほ,へ
- サークル番号形式: 数字のみ、各島 左右2列×6〜11行
- 特徴: 同じひらがなブロックが縦に複数並ぶ

### 西2ホール
- 島の配置: ち,た,そ,せ,す,し,さ,こ,け,く,き / が,お,え,う,い
- サークル番号形式: 数字ペア、各島 2列×6〜8行

### 南1ホール
- 島の配置: a, t, s, r, q, p, o, n, m, l, k
- サークル番号形式: 純整数、各島 2列×6〜9行

### 南2ホール
- 島の配置: a〜j（上下2列）
- サークル番号形式: 純整数、各島 2列×5〜9行

## 全体配置（ビッグサイト）

```
         [東1-3]  [東7]
[西1-2]             
         [南1-2]
```

- 左: 西1-2（縦長）
- 右: 東1-3（上）・東7（下）
- 中央下: 南1-2（横長）

## 制作時の注意点

1. 著作権配慮: 公式PDFの配色・フォント・装飾は使わず、ホール構造と配置という「事実」のみを表現
2. SVG の出力先: `app/maps/` 配下（アプリが読み込む場所）
   - 既存: map_east123.svg / map_east7.svg / map_west12.svg / map_south12.svg / map_overview.svg
3. 軽量性: 画像・外部フォントは使わず、フラットな配色で（省電力・低通信）
4. 島の中にサークル番号を記載する（公式マップと同じ構造）
